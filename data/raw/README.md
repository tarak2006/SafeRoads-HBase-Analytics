# US Accidents Dataset (1.4 GB)

Due to GitHub's 100 MB file size limit, the full raw 1.42 GB CSV file (`US_Accidents_1.4GB.csv`) is excluded from Git tracking.

### Dataset Source
- **Origin**: [Kaggle US Accidents Dataset](https://www.kaggle.com/datasets/sobhanmohammadpour/us-accidents)
- **Raw File Name**: `US_Accidents_1.4GB.csv` (1.42 GB, 3,864,198 rows)
- **Included Starter Data**: `data/processed/accidents_cleaned_sample.tsv` (16 MB, 100,000 rows) is committed with the repository so all MapReduce jobs and Hive queries run out of the box immediately without manual downloads!
